# Hotel Booking Demand Analysis

## Objective
Analyse booking data from a city hotel and a resort hotel in Portugal to
understand cancellations and revenue, and recommend ways to reduce
cancellations.

## Dataset
- Source: Kaggle, Hotel Booking Demand (Antonio, Almeida and Nunes, 2019)
- 119,390 rows, 32 columns
- Period: July 2015 to August 2017
- Licence: CC BY 4.0
